# AI Solutions — Corporate Website

A full-stack corporate website built for AI Solutions using React.js, Express.js, MySQL, and Tailwind CSS.

## Tech Stack
- **Frontend:** React.js (Vite) + Tailwind CSS v4
- **Backend:** Express.js + Node.js
- **Database:** MySQL
- **Authentication:** JWT + bcrypt

## Pages
- Home
- Solutions
- Reviews
- TaskeroSuite Detail Page
- Promotional Events
- Contact Us
- Admin Dashboard

## Setup Instructions

### Backend
1. Navigate to `aisbackend/`
2. Run `npm install`
3. Create a `.env` file using `.env.example` as a template
4. Run `node createAdmin.js` to create the admin account
5. Run `npm start`

### Frontend
1. Navigate to `aisfrontend/`
2. Run `npm install`
3. Run `npm run dev`
